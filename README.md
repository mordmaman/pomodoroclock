# Pomodoro

A calm focus timer. Installable PWA, hosted on GitHub Pages.

- Your own named presets (focus / short break / long break / sessions before a long break)
- Parking lot for stray thoughts, shown at each break
- Background drifts calmly as the session goes on
- Kids mode with a filling jar, growing plant and stars
- Stats: today, streaks, this week, 14-day chart, time of day

Everything is stored locally in the browser. Single `index.html`, CONFIG block at the top of the script.
